How These Are Made
Each construction is read from its GeoGebra file in the archive and rebuilt with the archive's own checker (tools/verify.py), in the order it was drawn. The sentences are written from the file itself, so they name the points as the file does. "Steps that count" are the ones the result depends on: those are what the chart counts. The GeoGebra files stay the second source of truth: open any of them in GeoGebra to check a step for yourself. Each entry's notes give its history and its original source.
Draw It Yourself
The best way to learn these is with a real compass on real paper, then again in GeoGebra to measure. Try a different radius: the accuracy does not change, because every step scales with the circle. Then try changing one step and see whether you land closer. That is exactly how most of the methods in the charts were found.
