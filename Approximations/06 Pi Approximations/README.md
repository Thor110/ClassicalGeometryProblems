# π Approximations

Every construction that rectifies the circle also approximates π: halve the constructed
circumference of a circle of radius 1 and the result is a length of π. The halving is a midpoint,
which the counting rules do not count, so a π approximation has the same accuracy and the same
circles and lines as the rectification it comes from.

So the π chart on the website is not a separate list. It is worked out from the circle
rectification chart, entry for entry, and shows each one's value of π and how many decimal places
of π it gets right. A new rectification of the circle appears on both charts.

The files here are Edward James Gordon's π versions of his rectifications, from his GeoGebra
account, each with the halving step drawn in. They are linked from the π chart beside the
rectification each one comes from:
